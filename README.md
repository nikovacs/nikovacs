# Nikolas Kovacs

Frontend platform engineer. I build the tooling and frameworks other engineers build on.

**Day job** — Lockheed Martin. Subject matter expert and Scrum Master for the framework behind [CommandIQ®](https://www.lockheedmartin.com/en-us/products/CommandIQ.html), a command-and-control platform. Angular, Nx, module federation, Stencil.

**Nights** — [Vici Online](https://vicionline.com), a platform for building multiplayer games with the ordinary web stack:

- C++ engine — client, server, shared core — with an embedded JavaScript runtime
- Game logic authored in TypeScript against a typed engine API; GUIs in RML/RCSS, RmlUi's HTML and CSS analogues
- Browser-based animation and level editors, each on a Rust core compiled to a C FFI, a C++ wrapper, and WebAssembly

Both live in private repositories — one for the obvious reason, the other because it isn't finished. This profile is a landing page rather than a portfolio; the work is at [vicionline.com](https://vicionline.com).

Interested in framework-agnostic component systems, developer experience, and the boundary problems that show up once a platform has more than one consumer.
